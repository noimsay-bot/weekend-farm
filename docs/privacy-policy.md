# 개인정보처리방침 (초안)

> 공개 배포 대비 초안입니다. 배포 결정 시 서비스 운영자 정보, 시행일, 연락처를 채우고 법률 검토를 거쳐 게시합니다.

주말텃밭(이하 "서비스")은 이용자의 개인정보를 소중히 다루며, 「개인정보 보호법」에 따라 다음과 같이 개인정보를 처리합니다.

## 1. 수집하는 개인정보 항목과 목적

| 항목 | 수집 시점 | 목적 |
|---|---|---|
| 이메일 주소, 비밀번호(암호화 저장) | 회원가입 | 로그인, 계정 식별, 공동 농장 멤버 구분 |
| 농장 위치(위도·경도), 농장 이름·크기 | 농장 만들기·설정 | 지역 날씨 예보·관측 조회, 지역별 재배 시기 적용, 농장 도착 확인 |
| 현재 위치 | 앱을 열 때(권한 허용 시) | 농장 반경 안인지 확인해 기록 입력을 돕기 위함. 위치 값은 서버에 저장하지 않음 |
| 작업 기록 사진 | 작업 기록 작성 | 작물 히스토리·작기 결산 표시 |
| 작업 기록(날짜·작업 종류·메모) | 작업 기록 작성 | 재배 일정·알림·결산 제공 |
| 푸시 알림 구독 정보(브라우저 발급 주소·키) | 알림 켜기 | 알림 발송 |

## 2. 보관 기간

- 회원 탈퇴 또는 농장 삭제 시 지체 없이 파기합니다.
- 관련 법령에 따라 보관이 필요한 경우 해당 기간 동안 보관합니다.

## 3. 제3자 제공

서비스는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 같은 농장에 초대로 합류한 멤버는 그 농장의 계획·기록·사진을 함께 볼 수 있습니다.

## 4. 처리 위탁

| 수탁자 | 위탁 업무 |
|---|---|
| Supabase Inc. | 데이터베이스·인증·파일 저장 |
| Vercel Inc. | 웹 서비스 호스팅 |
| 브라우저 푸시 서비스(Google 등) | 푸시 알림 전달 |

날씨 조회 시 기상청 API에는 농장 좌표로 계산한 예보 격자 번호와 관측소 번호만 전송되며, 이용자 식별 정보는 전송하지 않습니다.

## 5. 이용자의 권리

이용자는 언제든지 자신의 개인정보를 조회·수정·삭제하거나 처리 정지를 요구할 수 있습니다. 위치 권한과 알림 권한은 기기 설정에서 언제든 철회할 수 있습니다.

## 6. 안전성 확보 조치

- 모든 데이터는 농장 멤버만 접근할 수 있도록 데이터베이스 행 단위 접근 제어(RLS)를 적용합니다.
- 사진은 비공개 저장소에 보관하고 멤버에게만 일정 시간 유효한 주소로 제공합니다.
- 비밀번호는 인증 서비스에서 암호화하여 저장합니다.
