# 공공데이터 출처 표시 (초안)

> 공개 배포 시 앱 설정 화면과 이 문서에 게시합니다. 각 기관의 이용 조건(이용허락범위)을 배포 전에 다시 확인합니다.

## 작물 재배 정보

- **농촌진흥청 농사로(www.nongsaro.go.kr) OpenAPI**
  - 텃밭가꾸기 정보, 농작물재해예방정보, 주간농사정보
  - 앱에 표시하는 재배 수치(적정 기온, 재식거리, 수확까지 일수 등)는 위 원문에서 추출해 관리자가 원문과 대조·승인한 값입니다. 각 작물 화면에 원문 링크를 표시합니다.

## 비료

- **공공데이터포털(data.go.kr) — 농촌진흥청 국립농업과학원_작물별 비료 표준사용량 처방 정보**
  - 질소·인산·칼리 성분량(kg/10a)을 받아 앱에서 1평·포기당 제품량으로 환산해 표시합니다.

## 농약

- **농촌진흥청 농약안전정보시스템(psis.rda.go.kr) OpenAPI — 농약안전사용지침**
  - 성분명, 작용기작, 희석배수, 안전사용기준. 이용 조건: 출처표시, 변경금지.
  - 희석배수를 물 1L 기준 약량으로 바꿔 보여주는 것은 단위 환산이며 원자료 값은 바꾸지 않습니다.

## 날씨

- **기상청 — 공공데이터포털 제공**
  - 단기예보 조회서비스, 기상특보 조회서비스, 지상(종관, ASOS) 일자료 조회서비스
  - 관측값은 농장에서 가장 가까운 관측소 기준이라 실제 밭과 차이가 있을 수 있습니다.
